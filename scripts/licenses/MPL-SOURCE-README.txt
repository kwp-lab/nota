Nota MPL-2.0 dependency source archive
======================================

This archive contains the exact Cargo registry source directories for the
MPL-2.0 crates included in the corresponding Nota Windows release. The files
are unmodified copies selected from the locked Windows x64 dependency graph.

Each directory retains its upstream Cargo.toml, source files, copyright
notices, and license files. See THIRD_PARTY_SOURCES.md in the release for the
version inventory and upstream repository links.

Nota's own source is available at https://github.com/kwp-lab/nota under MIT.
